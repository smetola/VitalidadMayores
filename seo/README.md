# 📁 CARPETA SEO - VITALIDAD MAYORES

## 📋 Contenido de esta carpeta:

### 🔍 **robots.txt**
- Archivo que indica a los buscadores (Google, Bing, etc.) qué páginas pueden indexar
- Incluye la ubicación del sitemap
- Configurado para optimizar el SEO

### 🗺️ **sitemap.xml**
- Mapa del sitio web para buscadores
- Lista todas las páginas importantes con metadatos
- Incluye imágenes y frecuencia de actualización
- Ayuda a Google a indexar mejor la web

### 📱 **site.webmanifest**
- Configuración para Progressive Web App (PWA)
- Permite que la web se comporte como una app móvil
- Mejora el SEO móvil y la experiencia de usuario

## ⚠️ IMPORTANTE:

### 📝 **Cuándo modificar estos archivos:**
- **robots.txt**: Si añades nuevas páginas que no quieres que indexe Google
- **sitemap.xml**: Cuando añadas/elimines páginas o cambies URLs
- **site.webmanifest**: Si cambias el nombre del negocio o colores de marca

### 🚫 **NO tocar si no sabes lo que haces:**
- Estos archivos afectan directamente al SEO
- Un error puede hacer que Google deje de indexar la web
- Si necesitas cambios, consulta con un experto en SEO

### 🔧 **Para desarrolladores:**
- Los archivos deben estar accesibles desde la raíz del servidor
- robots.txt debe estar en `/robots.txt` (no en `/seo/robots.txt`)
- sitemap.xml debe referenciarse correctamente en robots.txt
- El manifest debe estar enlazado en el HTML principal
